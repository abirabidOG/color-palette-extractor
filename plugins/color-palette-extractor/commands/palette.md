---
description: Extract a colour palette from a photo or logo as HEX codes
argument-hint: <image-file> [--colors 3|5|8]
---

Extract a colour palette from the given image using the
color-palette-extractor skill.

Use the color-palette-extractor skill to extract a palette of 3, 5, or 8
colours from `$ARGUMENTS`, locally, with the bundled sharp script. Report the
HEX codes exactly as the script prints them, most dominant first. Never
invent or adjust a colour.
